## 브라우저 수동 체크 순서

1. 새 프로필에서 앱을 열고 캔버스가 화면 안에 맞춰지는지 확인한다.
2. 탭 점, 느린 선, 빠른 선과 캔버스 밖으로 나갔다 돌아오는 선을 그린다.
3. 그리던 중 두 번째 손가락을 넣고 이동·핀치한 뒤 다시 한 손가락으로 그린다.
4. 버튼 undo/redo와 두 손가락 탭 undo를 확인한다.
5. 새로고침 뒤 작업, 제목, 보기 변환, undo 가능한 히스토리가 복원되는지 확인한다.
6. 네트워크를 끊고 다시 열어 그리기·저장·PNG가 동작하는지 확인한다.
7. 새 작업 PNG를 열어 정확히 1080×1080이며 화면 확대·이동이 결과에 들어가지 않았는지 확인한다.
8. 세로 320px, 가로, 200% 글자 크기에서 버튼과 캔버스가 서로 가리거나 페이지 스크롤이 드로잉을 방해하지 않는지 확인한다.

## 아직 실기기에서 확인해야 하는 항목

- iOS Safari 탭과 홈 화면 설치 앱의 포인터 캡처, 가장자리 뒤로가기, 공유 취소
- Android Chrome 설치 앱의 멀티터치 오탐, 다운로드 파일 위치 안내
- 화면 회전과 앱 전환 직전 IndexedDB 커밋 완료율
- 저사양 기기의 p95 입력 반응, rAF 큐 지연, 30분 메모리 안정성
- 실제 오프라인 냉시작과 대기 서비스 워커 업데이트 승인 흐름
- VoiceOver/TalkBack의 캔버스 설명과 선택 버튼 상태 발화
